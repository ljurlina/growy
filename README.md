# Growy

> An Android app that helps you keep your houseplants alive by reminding you when to water them. Designed and built with a focus on a friendly, playful interface.

## Features
- Choose which plants you own from a plant library or add your own
- Set a custom watering interval for your specific plants
- Log when a plant was last watered
- Watering calendar showing today's, tomorrow's and upcoming plants to water
- Personalised welcome screen with your name

## Design
The UI was designed in Figma, with a warm, limited colour palette and a mix of serif display typography and friendly illustrations.

## Built with
Kotlin, Android Studio, Figma

## Getting started
1. Clone the repository
2. Open it in Android Studio
3. Run on an emulator or a physical device
